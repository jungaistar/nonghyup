ChatGPT

가장 범용적인 올라운더 — Custom GPT와 데이터 분석으로 사무 업무 자동화

가장 널리 쓰이는 생성형 AI로, 문서작성·요약·번역·데이터 분석·이미지 생성까지 폭넓게 처리한다. Custom GPT로 공지·보고 양식에 특화한 나만의 어시스턴트를 만들 수 있고, Code Interpreter로 엑셀·CSV를 코딩 없이 분석한다. 사무관리 전반의 반복 업무를 자동화하는 데 강하다.

■강점

  • 범용성 — 공지·기안·보고·번역 등 거의 모든 사무 업무 처리
  • Custom GPT — 코딩 없이 업무 특화 봇 제작·부서 공유
  • Code Interpreter — 엑셀·CSV 업로드만으로 데이터 분석·차트
  • 멀티모달 — 표·스캔 문서 이미지 분석(Vision), 이미지 생성
  • Tasks — 주간 보고 등 정기 업무 예약 자동 실행

■시작하기

  1. chatgpt.com 접속 후 구글 계정 등으로 로그인
  2. 상단에서 모델 선택(빠른 응답/추론 모델)
  3. 메시지 입력창에 파일·이미지 첨부 가능
  4. 자주 쓰는 작업은 Custom GPT로 저장해 재사용

■주요 기능

Custom GPT

회사 공지·보고 양식·자료를 넣은 전용 어시스턴트를 만들어 부서별로 공유.

Code Interpreter

판매·업무 데이터 파일 업로드 → 분석·시각화·리포트. 코딩 지식 불필요.

Vision

스캔한 문서·표·양식 이미지를 분석해 정보 추출·표 변환.

Web 검색 · Tasks

실시간 정보 검색 + 반복 보고 업무 예약 실행.

■기능별 사용법

Custom GPT

무엇 코딩 없이 사무 업무에 특화된 나만의 GPT를 만들어 부서와 공유한다. 지시문·양식·동작 규칙을 고정할 수 있다.

방법 Explore GPTs → Create → Configure,이름·설명·지시문(Instructions) 입력,Knowledge에 공지·보고 양식 PDF 업로드,미리보기로 테스트 후 링크 공유

Tip “업로드한 사내 양식을 따르고, 없으면 확인 필요로”라고 규칙을 박아두면 결과가 일관된다.

Code Interpreter (데이터 분석)

무엇 엑셀·CSV를 올리면 코드를 자동 실행해 분석·시각화·리포트를 만든다. 코딩 지식이 필요 없다.

방법 데이터 파일 업로드,“월별 판매 추이를 막대그래프로” 등 자연어로 요청,결과 차트·표를 이미지/파일로 다운로드

Tip 원하는 그래프 종류와 축을 명시하면 한 번에 원하는 결과가 나온다.

Vision (문서·표 이미지 분석)

무엇 스캔 문서·손글씨 양식·표 이미지를 이해해 정보를 추출하거나 디지털 표로 변환한다.

방법 이미지 첨부,“항목·수치를 표로 정리” 요청,불확실 항목은 “확인 필요” 표기 지시

Tip 손글씨·저화질은 오독 가능 — 핵심 수치는 사람이 검수.

이미지 생성 (DALL·E)

무엇 설명만으로 사내 안내물·행사 포스터·다이어그램 초안 이미지를 생성한다.

방법 “~한 분위기의 ~이미지” 묘사,비율·스타일·텍스트 포함 여부 지정,초안 후 부분 수정 요청

Tip 상표·실제 인물·정확한 로고 재현에는 부적합하다.

Tasks (예약 자동화)

무엇 정해진 시각에 반복 사무 업무를 자동 실행하도록 예약한다.

방법 “매주 금요일 16시에 ~ 생성” 형태로 Task 등록,출력 형식·검수 항목 지정,결과 알림 확인

Tip 생성물은 사람이 검수하는 게이트를 반드시 둔다.

■사무관리 활용

문서작성·공지

Custom GPT로 사내 문체·양식을 학습시켜 공지문·기안문 초안 자동화.

보고서 자동화

주간·월간 보고 템플릿 기반 자동 초안 생성으로 일관성 확보.

데이터 분석

판매·업무·고객 데이터를 업로드해 추세·이상치 분석과 차트 생성.

■실습

실전

실습 ① 부서 전용 Custom GPT 만들기

목표 총무팀 공지·기안 작성을 돕는 전용 GPT를 코딩 없이 구축한다.

  1. ChatGPT → ‘GPT 만들기(Explore GPTs > Create)’ 진입
  2. 이름·설명 설정: “총무팀 공지·기안 어시스턴트”
  3. Instructions에 역할·문체·양식 규칙 입력(아래 프롬프트 참고)
  4. Knowledge에 사내 공지·기안 양식 PDF 업로드
  5. 대화로 테스트 후 ‘부서 공유’ 링크 발급
실전

실습 ② Code Interpreter로 판매 데이터 분석

목표 월별 사료 판매 엑셀을 업로드해 추세와 이상치를 자동 분석·시각화한다.

  1. 판매 데이터 파일(.xlsx/.csv) 업로드
  2. “품목별 매출 상위 10개를 막대그래프로” 요청
  3. “월별 매출 추세선과 이상치 표시” 요청
  4. “전월 대비 급증·급감 품목과 원인 가설” 요청
입문

실습 ③ Vision으로 종이 양식 디지털화

목표 손글씨 신청서·스캔 표에서 정보를 자동 추출한다.

  1. 스캔 문서 또는 손글씨 양식 사진 업로드
  2. “이 양식의 항목·값을 표로 정리” 요청
  3. “손글씨 표를 디지털 표로 변환(불명확한 글자는 [?] 표기)” 요청
심화

실습 ④ Tasks로 주간 보고 자동화

목표 매주 정해진 시각에 반복 보고 업무를 자동 실행시킨다.

  1. “매주 금요일 오후 4시에 이번 주 업무 요약 템플릿을 생성” 형태로 Task 등록
  2. 생성 결과를 검수하는 체크 항목 지정
  3. 필요 시 Custom GPT와 결합해 사내 보고 양식으로 출력
입문

실습 ⑤ 이미지 생성으로 사내 행사 안내물

목표 사내 행사·캠페인 안내를 한눈에 보이는 포스터 이미지로 만든다.

  1. ChatGPT 입력창에서 이미지 생성을 요청
  2. 문구·비율·분위기 지정
  3. 초안 후 문구 수정 요청

■추천 프롬프트

공지문 작성

Prompt 
너는 농협사료 총무팀 담당자다. 아래 내용으로 전 직원 대상 사내 공지문을 제목·본문·문의처 형식으로 작성해줘. 확정 안 된 일정은 “확인 필요”로 표기해줘.

회의록 요약

Prompt 
아래 회의록에서 결정사항과 할 일만 뽑아 “구분/내용/담당/기한” 표로 정리해줘. 원문에 없는 내용은 추가하지 마.

데이터 분석

Prompt 
첨부한 판매 실적 CSV를 분석해 품목별 매출 TOP10과 월별 매출 추세를 차트로 그려줘.

■활용 사례

사내 문서 작성 표준화 총무·인사

문제 담당자마다 공지·기안 문체와 양식이 제각각이고 작성 시간이 김.

해결 Custom GPT에 사내 양식·문체 규칙을 학습시켜 공지·기안 초안 자동 생성 → 담당자 검수.

결과 문서작성 시간 단축, 사내 문서 톤·양식 일관성 확보.

판매·업무 데이터 인사이트 영업지원·기획

문제 판매·업무 데이터가 엑셀에 쌓이지만 분석 인력이 없어 활용 못 함.

해결 Code Interpreter에 데이터 업로드 → 추세·이상치·증감 요인 자동 분석.

결과 실적 인사이트 도출, 임원 보고 자료 제작 시간 대폭 절감.

부서 보고서 어시스턴트 전부서

문제 주간·월간 보고서 양식·품질이 담당자별로 제각각.

해결 사내 보고 양식을 넣은 Custom GPT로 보고서 초안 표준화.

결과 보고서 작성 시간 단축, 산출물 품질 균일화.

신입 업무 어시스턴트 인사·교육

문제 신입사원 문서·절차 안내에 선배 시간이 과도하게 소모됨.

해결 Custom GPT에 사내 규정·FAQ를 넣어 24시간 질문 가능한 안내 봇 운영.

결과 선배 문의 응대 시간 절감, 신입 적응 속도 향상.

■프롬프트 요령

  • “너는 ○○팀 담당자다”로 역할을 먼저 지정한다.
  • 반복 업무는 Custom GPT로 만들어 두고 재사용한다.
  • 데이터는 파일로 올리고 “표/차트로” 출력 형식을 지정한다.

■한계와 유의점

  • 학습 시점 이후 최신 정보는 웹 검색을 켜야 정확하다(기본 답변은 과거 시점일 수 있음).
  • 수치·통계·규정·인용문은 환각 가능 — 반드시 원문/공식 자료로 검수한다.
  • 사내·고객·거래처 자료는 데이터 학습 옵트아웃 또는 Team/Enterprise 정책을 확인한 뒤 입력한다.
