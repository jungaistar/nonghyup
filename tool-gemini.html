Gemini

Google 생태계 통합 + 초대형 컨텍스트 + Deep Research

Google Workspace(Gmail·Docs·Sheets·Drive)와 깊게 통합되어 업무 문서·메일을 직접 참조해 작업한다. 초대형 컨텍스트로 방대한 자료를 한 번에 다루고, Deep Research로 출처를 인용한 시장·업계 조사 보고서를, NotebookLM으로 내 자료 기반 어시스턴트를 만든다. 이미지·영상 멀티모달도 강하다.

■강점

  • Workspace 통합 — Gmail·Docs·Sheets·Drive 직접 연동
  • 초대형 컨텍스트 — 대량 자료 일괄 처리
  • Deep Research — 출처 인용 시장·업계 조사 보고서 자동 생성
  • NotebookLM — 업로드한 규정·자료 기반 Q&A·요약
  • 멀티모달 — 이미지·영상 분석/생성

■시작하기

  1. gemini.google.com 접속(구글 계정)
  2. 모델/플랜 선택
  3. Workspace 문서·메일 연동 허용
  4. Deep Research·NotebookLM 등 목적별 기능 선택

■요금제

구분가격내용
Free무료기본 모델

■주요 기능

Workspace 통합

메일 초안·문서 요약·시트 분석을 앱 안에서 바로.

Deep Research

주제를 주면 다수 출처를 조사해 인용 포함 보고서 작성.

NotebookLM

내 규정·자료 PDF를 올려 근거 기반 답변·오디오 요약.

Gems

용도별 맞춤 어시스턴트 생성.

■기능별 사용법

Deep Research

무엇 주제를 주면 다수 웹 출처를 조사해 인용이 달린 시장·업계 조사 보고서를 자동 작성한다.

방법 Deep Research 선택,조사 주제·범위 입력,생성된 리서치 계획 검토·수정,보고서 생성 후 각주 검수

Tip 핵심 수치는 각주 원문으로 반드시 재확인.

NotebookLM

무엇 내 규정·매뉴얼·PDF를 올려 그 자료 근거로만 답하는 어시스턴트와 오디오 요약을 만든다.

방법 notebooklm.google.com → 새 노트북,소스(PDF·문서) 업로드,근거 인용과 함께 질의,오디오 개요 생성

Tip 사내 규정 Q&A·신입 교육 자료로 적합.

Workspace 통합

무엇 Gmail·Docs·Sheets·Drive 안에서 요약·초안·분석을 바로 수행한다.

방법 문서/메일에서 Gemini 호출,“요약/답장 초안/표 분석” 요청,결과를 문서에 바로 반영

Tip “이 문서 근거로”라고 지정해 정확도를 높인다.

멀티모달(이미지·영상)

무엇 이미지·영상을 이해·생성한다. 영상 요약·이미지 분석에 강하다.

방법 이미지/영상 첨부 또는 링크,분석·요약·생성 요청,형식 지정

Tip 생성물의 사실성·저작권을 확인한다.

Gems (맞춤 어시스턴트)

무엇 자주 쓰는 작업을 역할·형식이 고정된 맞춤 봇으로 저장한다.

방법 Gems → 새 Gem,지시문(역할·톤·출력형식) 입력,저장 후 재사용

Tip 거래처 안내 메일·회의록 요약 등 반복 업무에 적합.

■사무관리 활용

시장·업계 조사

Deep Research로 사료·축산 시장 동향을 출처 인용 보고서로 빠르게 초안화.

규정·자료 Q&A

NotebookLM에 규정을 올려 근거 기반 Q&A 어시스턴트로 활용.

메일·문서 자동화

Workspace 문서·메일 기반 요약·답장·분석 자동화.

■실습

실전

실습 ① Deep Research로 시장·업계 보고서

목표 사료·축산 시장을 출처 인용 보고서로 자동 조사한다.

  1. Gemini → Deep Research 선택
  2. 조사 주제·범위·기간 지정
  3. 생성된 리서치 계획 검토·수정
  4. 보고서 생성 후 각주 출처 검수 → Docs로 내보내기
실전

실습 ② NotebookLM 규정 어시스턴트

목표 사내 규정·업무 매뉴얼을 올려 근거 기반 Q&A·오디오 요약을 만든다.

  1. notebooklm.google.com 접속 → 새 노트북
  2. 규정·매뉴얼 PDF 여러 개 업로드(소스)
  3. 질문하면 근거 인용과 함께 답변
  4. “오디오 개요(팟캐스트)” 생성으로 교육자료화
입문

실습 ③ Workspace 업무 자동화

목표 Gmail·Docs·Sheets에서 바로 초안·요약·분석을 수행한다.

  1. Gmail에서 긴 거래처 문의 스레드 “요약 + 답장 초안” 요청
  2. Docs에서 회의록 “핵심 결정·할 일 추출”
  3. Sheets에서 판매 데이터 “요약·차트” 요청
심화

실습 ④ Gems로 반복 업무 어시스턴트

목표 자주 쓰는 작업을 Gem(맞춤 어시스턴트)으로 고정한다.

  1. Gemini → Gems → 새 Gem 만들기
  2. 역할·말투·출력형식을 지시문으로 고정
  3. 예: “거래처 안내 메일 Gem”, “회의록 요약 Gem”
실전

실습 ⑤ Workspace로 회의록·메일 자동화

목표 Docs 회의록 요약과 Gmail 답장 초안을 앱 안에서 처리한다.

  1. Docs 회의록에서 Gemini 호출
  2. 핵심·할 일 추출 요청
  3. Gmail에서 답장 초안 생성

■추천 프롬프트

시장 조사

Prompt 
(Deep Research) 국내 배합사료·축산 시장(규모·성장률·원자재 가격·정책)을 출처와 함께 조사해줘.

규정 Q&A

Prompt 
(NotebookLM) 업로드한 규정 근거로 경조사 지원 항목·금액·절차를 근거 위치와 함께 정리해줘.

메일 처리

Prompt 
(Gmail) 이 거래처 문의 스레드를 3줄로 요약하고 정중한 답장 초안을 작성해줘. 단가·납기 미정 내용은 [확인]으로 표기.

■활용 사례

시장·업계 조사 보고서 기획·영업지원

문제 사료·축산 시장 1차 조사에 수일 소요, 출처 정리가 번거로움.

해결 Deep Research로 규모·가격·정책·이슈를 출처 인용 보고서로 자동 작성 후 검수.

결과 조사 초안 시간 대폭 단축, 근거 기반 의사결정.

규정 근거 교육자료 인사·교육

문제 신입 교육용 규정 안내 자료 제작에 시간이 많이 듦.

해결 NotebookLM에 규정을 올려 Q&A + 오디오 개요(팟캐스트형) 생성.

결과 근거 기반 교육 Q&A와 오디오 요약 확보.

업무 메일·문서 자동화 전부서

문제 반복되는 거래처 응대 메일·회의록 정리에 시간 소모.

해결 Workspace 통합으로 Gmail 요약·답장 초안, Docs 회의록 핵심 추출.

결과 맥락 전환 없이 앱 안에서 즉시 처리, 생산성 향상.

전사 지식 검색 총무·기획

문제 부서별 자료가 흩어져 필요한 정보를 찾기 어려움.

해결 NotebookLM·Workspace로 자료를 모아 근거 기반 Q&A 환경 구성.

결과 정보 탐색 시간 절감, 근거 기반 답변.

■프롬프트 요령

  • Workspace 문서를 직접 참조시키고 “이 문서 근거로”라고 지정한다.
  • 리서치는 Deep Research, 내 자료 Q&A는 NotebookLM으로 구분해 쓴다.
  • 출처가 붙은 보고서를 요청하고 각주를 반드시 검수한다.

■한계와 유의점

  • Deep Research·검색 결과의 출처·수치는 직접 클릭해 검수해야 한다.
  • Workspace 연동은 조직 계정 권한·공유 범위를 먼저 확인한다.
  • 결과의 최신성·품질은 모델/요금제에 따라 달라진다.
