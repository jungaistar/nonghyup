Google Sheets

데이터 정리·집계·기초 분석 + AI와 결합해 인사이트까지

웹 브라우저에서 바로 쓰는 스프레드시트로, 판매·업무·고객 샘플 데이터를 정리·집계·기초 분석하는 사무관리의 기본 도구다. 표를 깔끔히 정돈한 뒤 그 표를 ChatGPT·Claude에 붙여넣으면 요약·인사이트·차트 아이디어까지 얻을 수 있다. 구글 계정만 있으면 무료로 쓰고, 공동 편집과 실습 결과 제출에도 적합하다.

■강점

  • 데이터 정리 — 정렬·필터·중복 제거로 표를 빠르게 정돈
  • 집계·기초 통계 — SUM·AVERAGE·COUNTIF·피벗테이블로 요약
  • 차트 — 막대·꺾은선·원 그래프로 즉시 시각화
  • AI 결합 — 표를 AI에 붙여넣어 요약·인사이트·차트 아이디어 도출
  • 공동 편집 — 실시간 협업·댓글, 실습 결과 제출에 적합

■시작하기

  1. docs.google.com/spreadsheets 접속(구글 계정)
  2. 새 시트 생성 후 데이터 입력/붙여넣기
  3. 정렬·필터·함수로 표를 정돈
  4. 필요 시 표를 복사해 AI에 붙여넣어 요약 요청

■요금제

구분가격내용
Free무료구글 계정만 있으면 개인 무료 사용
Google Workspace조직 요금조직 계정·용량·관리 기능 확대

■주요 기능

정렬·필터

데이터를 조건별로 정렬·추출해 필요한 값만 빠르게 확인.

함수·수식

SUM·AVERAGE·COUNTIF·VLOOKUP 등으로 집계·조회 자동화.

피벗테이블

드래그만으로 항목별 합계·평균·건수를 요약.

차트

선택 범위를 막대·꺾은선·원 그래프로 즉시 시각화.

■기능별 사용법

데이터 정리(정렬·필터·중복 제거)

무엇 지저분한 표를 정렬·필터·중복 제거로 분석 가능한 형태로 정돈한다.

방법 데이터 → 범위 정렬,필터 만들기로 조건 추출,데이터 → 정리 → 중복 항목 삭제

Tip 분석 전 빈칸·표기 오류·중복부터 정리하면 결과가 정확해진다.

집계·기초 통계(함수·피벗)

무엇 함수와 피벗테이블로 항목별 합계·평균·건수를 빠르게 요약한다.

방법 =SUM/AVERAGE/COUNTIF 입력,삽입 → 피벗테이블,행·값 영역에 항목·수치 배치

Tip 피벗은 원본을 바꾸지 않고 여러 관점으로 요약할 수 있다.

차트 만들기

무엇 선택 범위를 그래프로 즉시 시각화해 추세·비중을 한눈에 본다.

방법 범위 선택 → 삽입 → 차트,차트 종류(막대·꺾은선·원) 선택,제목·축·범례 편집

Tip 추세는 꺾은선, 구성비는 원, 비교는 막대가 적합하다.

AI와 결합(표 붙여넣기)

무엇 정돈한 표를 ChatGPT·Claude에 붙여넣어 요약·인사이트·차트 아이디어를 얻는다.

방법 시트에서 표 범위 복사,AI에 붙여넣고 “요약·이상치·차트 제안” 요청,제안받은 관점으로 시트에서 차트 작성

Tip AI가 준 수치는 시트 원본과 대조해 검수한다.

■사무관리 활용

판매 데이터 집계

월별·품목별 판매를 피벗으로 요약하고 추세 차트로 시각화.

업무 현황 관리

취합·정산·이슈 목록을 필터·조건부 서식으로 관리.

AI 분석 준비

데이터를 정돈해 AI에 붙여넣기 좋은 형태로 만들고 인사이트 요청.

■실습

입문

실습 ① 판매 데이터 정리·집계

목표 흩어진 판매 데이터를 정렬·피벗으로 요약한다.

  1. docs.google.com/spreadsheets에 데이터 붙여넣기
  2. 필터로 결측·중복 정리
  3. 피벗테이블로 월별·품목별 매출 합계 요약
  4. 요약 표를 막대그래프로 시각화
입문

실습 ② 함수로 업무 현황 자동 집계

목표 COUNTIF·SUMIF로 업무·정산 현황을 자동 집계한다.

  1. 상태 열(완료/진행/보류) 입력
  2. =COUNTIF로 상태별 건수 집계
  3. =SUMIF로 담당·항목별 금액 합계
  4. 조건부 서식으로 지연 항목 강조
실전

실습 ③ 시트 데이터로 AI 인사이트 도출

목표 정돈한 표를 AI에 넘겨 요약·차트 아이디어를 받는다.

  1. 분석할 표 범위 복사
  2. ChatGPT/Claude에 붙여넣고 관점 지정
  3. AI가 제안한 지표·차트를 시트에서 구현
  4. AI 수치는 시트 원본과 대조 검수
실전

실습 ④ 실습 결과 제출용 시트 구성

목표 공동 편집 시트로 실습 결과를 취합·제출한다.

  1. 제출용 시트 생성(팀·항목 열 구성)
  2. 공유 링크로 편집 권한 부여
  3. 각자 결과·프롬프트·스크린샷 링크 입력
  4. 취합 탭에서 피벗으로 진행률 확인

■추천 프롬프트

표 요약

Prompt 
아래 시트 표를 보고 핵심 추세·이상치를 3가지로 요약하고, 적합한 차트를 제안해줘.

(표 붙여넣기)

인사이트 도출

Prompt 
아래 판매 데이터에서 영업지원에 쓸 인사이트 3가지와 근거 지표를 정리해줘.

(표 붙여넣기)

수식 도움

Prompt 
Google Sheets에서 담당자별 처리 건수를 세는 COUNTIF 수식과, 월별 매출 합계를 구하는 SUMIF 수식을 예시와 함께 알려줘.

■활용 사례

월간 판매 리포트 자동화 영업지원

문제 매월 판매 데이터를 수작업으로 집계·정리하는 데 시간 소모.

해결 피벗테이블로 월별·품목별 요약을 표준화하고, 표를 AI에 넘겨 인사이트 초안 작성.

결과 집계 시간 단축, 인사이트가 담긴 리포트로 품질 향상.

업무 현황 대시보드 총무·전부서

문제 업무·정산 현황이 흩어져 진행 상황 파악이 어려움.

해결 함수·조건부 서식으로 상태별 자동 집계 현황판 구성.

결과 진행률·지연 항목을 한눈에 파악, 관리 효율 향상.

고객 데이터 인사이트 영업지원·기획

문제 고객·거래 데이터가 쌓이지만 분석 관점을 잡기 어려움.

해결 정돈한 표를 AI에 붙여넣어 세그먼트 특징·인사이트·차트 제안을 받음.

결과 데이터 기반 영업지원 인사이트 확보.

실습 결과 취합 교육·운영

문제 교육 실습 결과 제출·취합이 번거로움.

해결 공동 편집 시트로 실시간 제출·취합, 피벗으로 진행 현황 확인.

결과 제출 취합 자동화, 미제출·누락 즉시 파악.

■프롬프트 요령

  • 분석 전 정렬·필터·중복 제거로 표를 먼저 정돈한다.
  • AI에 표를 붙여넣을 땐 “요약·이상치·차트 제안” 등 관점을 지정한다.
  • AI가 준 수치는 시트 원본과 대조해 검수한다.

■한계와 유의점

  • 대용량·복잡한 분석은 전용 BI 도구보다 느리거나 제한될 수 있다.
  • AI에 표를 붙여넣을 때 개인정보·거래처 정보는 비식별화 후 사용한다.
  • AI가 생성한 요약·수치는 시트 원본과 대조해 반드시 검수한다.
