# 농협사료 · 생성형 AI 사무관리 업무혁신 학습사이트 (인라인 정적본)

농협사료 임직원을 위한 **「생성형 AI 기반 사무관리 업무혁신 실무」 1일 8차시** 과정
학습사이트를, **HTML · CSS · JS 인라인 단일 파일** 25쪽으로 다시 만든 것입니다.

원본은 React + Vite + Tailwind + Supabase SPA 입니다(`_원본/`).
이 저장소의 `*.html` 은 **그 내용을 그대로 옮기되 빌드 도구도 네트워크도 없이
돌아가도록** 만든 결과물입니다. 파일을 더블클릭하면 바로 열립니다.

---

## 1. 바로 열어 보기

```
index.html  을 브라우저로 연다.  끝.
```

서버가 필요 없습니다. `file://` 로 열어도 목차 이동 · 프롬프트 복사 ·
진도 저장 · 모바일 서랍 메뉴가 전부 동작합니다.

## 3. 폴더 구조

```
nonghyup/
├─ *.html                 ← 완성본 25쪽 (학생에게 주는 것)
│
├─ _build/                ← "만드는 쪽" 자료
│  ├─ parts/
│  │  ├─ style.css          디자인 시스템 (NH 토큰 · 블록 14종 · 반응형)
│  │  └─ common.js          서랍 메뉴 · 프롬프트 복사 · 진도 저장
│  ├─ gen/
│  │  ├─ load.mjs           _원본 의 ES 모듈을 Node 에서 읽는다
│  │  ├─ blocks.mjs         본문 블록 14종 렌더러
│  │  ├─ shell.mjs          헤더 · 사이드바(6모드) · 푸터
│  │  ├─ scoring.mjs       프롬프트 자동 채점 (원본 evaluatePrompt 이식)
│  │  ├─ pages-core.mjs     홈 · 교재 · 차시 · 일정 · 실습 · 진도
│  │  ├─ pages-tools.mjs    도구 · 프롬프트 실습실 · 부록
│  │  └─ pages-about.mjs    제작의도 · 강사 · 회사
│  └─ build.mjs             위를 합쳐 *.html 을 만든다
│
├─ _원본/                 ← 원본 React 소스 (내용의 출처)
├─ docs/작업기록.md        무엇을 왜 그렇게 했는지
└─ setup-local.ps1 / .bat  D:\dev\nonghyup 으로 내려받기
```

### 다시 만들기

```bash
node _build/build.mjs
```

Node 18 이상이면 되고 **설치할 패키지가 없습니다.**
`_원본/src/data/` 의 내용이 바뀌면 이 한 줄로 25쪽이 다시 만들어집니다.

> 배포 워크플로가 CI 에서 같은 명령을 돌려 **커밋된 HTML 과 대조**합니다.
> `_build/` 나 `_원본/` 만 고치고 다시 만들지 않은 채 올리면 배포가 멈춥니다.
> 인라인 방식에서 가장 나기 쉬운 사고라 막아 두었습니다.

## 4. 외부 요청이 하나도 없습니다

강의실이 폐쇄망인 것을 전제로 만들었습니다. **브라우저 검증에서 25쪽 모두
외부 요청 0건**을 확인했습니다.

| 원본 | 이 정적본 |
|---|---|
| React · Vite · Tailwind CDN/번들 | 없음 — 순수 HTML + 인라인 CSS/JS |
| Supabase 로그인 · 진도 동기화 | 없음 — 진도는 `localStorage` 한 곳에만 |
| Font Awesome 아이콘 | 인라인 SVG · 이모지 |
| 웹폰트 CDN | 안 검. Pretendard 가 깔려 있으면 쓰고, 없으면 OS 기본 글꼴 |
| favicon 파일 | `data:` URI 로 심은 SVG |

즉 `*.html` 25개 말고는 **아무것도 필요 없습니다.** USB 로 옮겨도 똑같이 돕니다.

## 5. 반응형

| 폭 | 달라지는 것 |
|---|---|
| ~640px | 카드가 한 열, 타임라인이 세로로 접힘 |
| ~768px | 상단 가로 메뉴를 감추고 서랍으로 보냄 |
| ~1024px | 사이드바가 **서랍**으로 바뀜 (스크림 + ESC 닫기) |
| 1025px~ | 왼쪽 목차(272px) + 본문 |

지켜지는 것 — 브라우저로 확인 완료:

- **본문이 통째로 가로로 밀리지 않는다.** 넓은 표는 표 안에서만 스크롤한다.
- 입력 글자 16px 이상 (iOS 확대 방지) · 터치 대상 44px 이상
- 좁은 화면용 마크업을 따로 두지 않는다

## 6. 검증 상태

Chromium 으로 **25쪽 × 3폭(360 · 768 · 1440) = 75개 조합 전부 통과**.

```
가로 넘침 0 · 외부 요청 0 · 스크립트 오류 0
```

상호작용도 실제 클릭으로 확인했습니다 — 진도 저장(`localStorage`), 진도
대시보드 집계, 프롬프트 복사 버튼, 실습 표 21개, 도구 페이지 13개 섹션,
모바일 서랍. 자세한 것은 [`docs/작업기록.md`](docs/작업기록.md).
